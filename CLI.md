# The command line

This document lives at [docs/cli/design.md](docs/cli/design.md), and is
published with its diagram at <https://rangertaha.github.io/scour/cli/design.html>.

It is a design for the command surface, not a description of the one that ships:
five nouns, one rule, the four shortcuts that break it, and a migration table
from every command that exists today. Its companion is
[API.md](API.md), which puts the same five nouns over HTTP.

What ships today is documented at
<https://rangertaha.github.io/scour/cli/>.
