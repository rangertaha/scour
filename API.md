# The HTTP API

This document lives at [docs/server/api.md](docs/server/api.md), and is
published with its diagram at <https://rangertaha.github.io/scour/server/api.html>.

It is a design for the API surface, not a description of the one that ships: the
same five nouns as [CLI.md](CLI.md), one path rule, the run resource that long
work becomes, full parity across HTTP, the CLI and MCP, and a migration table
from every endpoint that exists today.

What ships today is documented at
<https://rangertaha.github.io/scour/server/>.
